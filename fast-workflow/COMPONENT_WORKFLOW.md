# Cursor Component Factory — Быстрый старт (fast-workflow)

Быстрая точка входа для фабрики разработки и интеграции компонентов в Cursor.
Практическая инструкция с командами: [USER_GUIDE.md](USER_GUIDE.md).

---

## Обязательное ядро
Всегда действует [CORE_WORKFLOW.md](CORE_WORKFLOW.md). Оно определяет единый сквозной цикл «Аналитик ↔ ИИ», стандарты контрактов (OpenAPI, Zod, AsyncAPI, 1C), принцип Zero-Manual Mocks, политику SemVer и границы ответственности.

---

## Выбор режима работы

### 1. Разработка компонента / модуля
Используйте [COMPONENT_REPO_WORKFLOW.md](COMPONENT_REPO_WORKFLOW.md), когда задача:
- Создает или модифицирует один компонент;
- Использует автоматические моки по контрактам (Zero-Manual Mocks);
- Выполняет изолированные локальные проверки;
- Готовит проверенную версию со статусом `Ready`.

Подключите контекстное правило:
```text
@.cursor/rules/component-repo-workflow.mdc
```

### 2. Интеграционный контур
Используйте [INTEGRATION_REPO_WORKFLOW.md](INTEGRATION_REPO_WORKFLOW.md), когда задача:
- Обновляет одну опубликованную зависимость версии `Ready`;
- Проверяет сквозную связь между компонентами;
- Запускает интеграционные и регрессионные автотесты;
- Фиксирует статус `Integrated` в реестре после одобрения человека.

Подключите контекстное правило:
```text
@.cursor/rules/integration-repo-workflow.mdc
```

## Матрица быстрого выбора

| Что нужно сделать? | Какой режим выбрать? |
|---|---|
| Создать репозиторий компонента? | **Инициализация компонента** (`/new-component`, `/new-repo`) |
| Создать интеграционный репозиторий? | **Инициализация интеграции** (`/new-integration`) |
| Написать/исправить код компонента или расширения 1С? | **Репозиторий компонента** (`COMPONENT_REPO_WORKFLOW.md`, `/implement`) |
| Сформировать контракт и поднять авто-мок? | **Репозиторий компонента** (`COMPONENT_REPO_WORKFLOW.md`, `/spec`) |
| Обновить версию зависимости в общем приложении? | **Интеграционный контур** (`INTEGRATION_REPO_WORKFLOW.md`, `/integrate`) |
| Проверить сквозной сценарий между двумя сервисами? | **Интеграционный контур** (`INTEGRATION_REPO_WORKFLOW.md`) |
| Нужно изменить код компонента и интеграцию одновременно? | **Разделить на две последовательные задачи!** |
