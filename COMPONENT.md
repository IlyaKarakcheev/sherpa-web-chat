# sherpa-web-chat

## Назначение
Легковесный автономный тонкий веб-клиент чата ассистента «Шерпа» для менеджеров компании-дистрибутора ПО с поддержкой сценария продаж (интеграция с 1С CRM, разбор спецификаций из писем Outlook, подбор сделок) и консультаций по реестру отечественного ПО.

## Архитектура «Тонкого клиента»
- **Размещение точки входа**: Главный `index.html` расположен в корне репозитория для поддержки локального доступа по протоколу `file:///` и серверного запуска (`http://`).
- **Отсутствие бизнес-эвристик в UI**: Клиент не распарсивает бизнес-строки (карточки сделок по разделителям) и не трансформирует ввод пользователя.
- **Server-Driven Markdown & Directives**: Сервер является единственным источником истины для форматирования ответов (`[Label](cmd:Command)`, `:::deal-card`, `:::placeholder`).
- **Передача команд "как есть"**: Клиент отправляет на сервер нажатую команду `cmd:Command` или введенный пользователем текст без скрытых трансформаций.
- **Модульная структура с универсальной совместимостью**:
  - `src/core/logger.js` (`ChatLogger`) — встроенное логирование событий и журналов;
  - `src/services/http-sherpa.service.js` (`HttpSherpaService`) — HTTP-клиент взаимодействия с REST API ассистента;
  - `src/services/service-factory.js` (`SherpaServiceFactory`) — фабрика динамического создания сетевого/мокового провайдера по настройкам;
  - `src/utils/markdown-renderer.js` (`MarkdownRenderer`) — утилитный рендерер безопасного парсинга Markdown, таблиц, инлайн-кнопок `[Label](cmd:Command)` и директив блоков (`:::deal-card`, `:::facts`, `:::placeholder`);
  - `src/app.js` (`SherpaChatApp`) — тонкий UI-контроллер Fluent UI и управление состоянием истории сообщений.

## Входы
- Сообщения пользователя (текстовые запросы по подбору ПО, совместимости, созданию и связыванию сделок в 1С CRM).
- Потоковые или дискретные ответы от API ассистента / мок-провайдера (включая эндпоинт приветствия `GET /api/v1/chat/greeting`, список подключенных сервисов `services`: 1C CRM, GliNER, и контекстный `placeholder`).
- Параметры конфигурации из панели настроек / URL / localStorage (`sherpa_settings`).

## Выходы
- Отображение диалога с ассистентом, форматированный вывод Markdown (таблицы, списки, выделения).
- Индикация доступности оркестратора (зеленая/красная точка) и серые теги подключенных сервисов (`1C CRM`, `GliNER`).
- Динамический Server-Driven `placeholder` поля ввода сообщений под текущий шаг диалога.
- Диалоговая обработка доступности подсистем (1C CRM, GliNER) внутри сообщений ассистента.
- Индикация набора текста, стрим-подключения к серверу при старте в Mock и Live («Подключение...») и системные сообщения сбоя оркестратора в ленте (`sender: 'system'`) с кнопкой «Повторить».
- Блокировка поля ввода, скрепки файлов и кнопки отправки на время активного запроса к серверу (`isConnecting` / `isBusy`).
- Встроенный журнал событий и диагностических логов (Logs & Diagnostics) с функцией копирования.

## Ответственность
- Семантический UI чата в дизайн-системе Fluent UI.
- Управление локальным состоянием истории сообщений.
- Интерактивное взаимодействие (Enter / Shift+Enter, кнопка сброса диалога, индикатор генерации).
- Предоставление встроенного мок-провайдера (Zero-Manual Mocks) для автономной работы и HTTP-клиента `HttpSherpaService` для боевого режима с живым бэкендом.
- Графическая панель настроек (Settings Modal) для переключения режимов Mock/Live, статусов связи и просмотра логов.

## Не отвечает за
- Бизнес-логику оркестрации LLM и RAG-поиска (ответственность `assistant-orchestrator` / `distributor-kb-service`).
- Прямое подключение к базам 1С и ERP.
