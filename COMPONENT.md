# sherpa-web-chat

## Назначение
Легковесный автономный веб-интерфейс чата ассистента «Шерпа» для менеджеров компании-дистрибутора ПО с поддержкой форматирования Markdown, списков позиций/лицензий, таблиц цен и встроенных моков.

## Входы
- Сообщения пользователя (текстовые запросы по подбору ПО, совместимости и лицензированию).
- Потоковые или дискретные ответы от API ассистента / мок-провайдера.

## Выходы
- Отображение диалога с ассистентом, форматированный вывод Markdown (таблицы, списки, выделения).
- Индикация набора текста и статусов сетевых ошибок.

## Ответственность
- Семантический UI чата в дизайн-системе Fluent UI.
- Управление локальным состоянием истории сообщений.
- Интерактивное взаимодействие (Enter / Shift+Enter, кнопка сброса диалога, индикатор генерации).
- Предоставление встроенного мок-провайдера для автономной работы без бэкенда.

## Не отвечает за
- Бизнес-логику оркестрации LLM и RAG-поиска (ответственность `assistant-orchestrator` / `distributor-kb-service`).
- Прямое подключение к базам 1С и ERP.
