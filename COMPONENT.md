# sherpa-web-chat

## Назначение
Тонкий клиентский пользовательский интерфейс (UI) чата для встраивания в боковую панель Microsoft Outlook (ширина 320–360px) или работы в автономном браузере. Обеспечивает отображение диалога с ИИ-оркестратором `sherpa-agent-server` через протокол REST/SSE, рендеринг разметки Markdown GFM, бейджей сущностей, индикаторов шагов исполнения, плашки контекстного ответа (Reply Banner), нумерованных кнопок быстрых ответов (Keyboard-First) и перехват ссылок 1С (`e1cib`) для копирования в буфер обмена с Toast-уведомлением.

## Входы
- Контекст открытого письма от родительского фрейма/Outlook (`subject`, `sender`, `body`, `manager_email`).
- Локальная загрузка бинарных файлов `.msg` / `.eml` через Drag-and-Drop или кнопку прикрепления.
- Поток событий SSE и HTTP REST ответы от `sherpa-agent-server` по контракту `contracts/front/sherpa-chat-protocol-v1.yaml`.
- Пользовательский ввод (текст, цифры клавиатуры `1..N`, клики по кнопкам, клик по действию `[↩ Ответить]`, горячая клавиша `Esc`).

## Выходы
- HTTP-запросы к серверному оркестратору:
  - `POST /v1/chat/session` (инициализация сессии письма)
  - `POST /v1/chat/session/upload` (отправка файла письма)
  - `POST /v1/chat/message` (отправка ответа с `reply_to_message_id` или текста кнопки)
  - `GET /v1/chat/stream?session_id=...` (подключение к SSE)
- Рендеринг интерфейса:
  - Список сообщений с поддержкой Markdown GFM (жирный шрифт, списки, таблицы, цитаты, e1cib-ссылки).
  - Чипсы извлеченных сущностей (`extracted_summary`: компании, номера сделок, ИНН, суммы).
  - Индикатор выполнения шагов оркестратора («Обрабатываю письмо...», «Ищу в 1С...»).
  - Компактная плашка цитирования (`Reply Banner` $\le 28$px) с кнопкой закрытия `[✕]` и поддержкой `Esc`.
  - Нумерованные кнопки Quick Replies (`1.`, `2.`, `3.`) для мыши и быстрого клавиатурного ввода.
  - Toast-нотификация `✔ Скопировано` при клике по ссылке `e1cib/data/...`.

## Ответственность
- Адаптивный рендеринг панели чата в ограниченной ширине (320–360px) с соблюдением дизайн-системы Microsoft Fluent UI v9 (`@fluentui/react-components`).
- Полная поддержка клавиатурной навигации и Keyboard-First выбора вариантов (`1`, `2`, `3`).
- Управление состоянием плашки реплая: показ при клике `[↩ Ответить]` или наличии `expected_input`, скрытие по `[✕]` или `Esc`.
- Безопасная обработка ссылок `e1cib/data/...` — копирование в буфер обмена через `navigator.clipboard.writeText` без передачи в протоколы ОС.
- Автономный запуск в браузере в режиме с Zero-Manual Mocks (MSW / Mock Server) без необходимости поднятия бэкенда.

## Не отвечает за
- Бизнес-правила FSM и маршрутизацию диалога (зона ответственности `sherpa-agent-server`).
- Парсинг бинарных файлов писем (зона ответственности `sherpa-email-parser`).
- Прямое взаимодействие с 1С:CRM (зона ответственности `1c-crm-gateway` / `sherpa-1c-crm-mock`).
- Интеграцию с Office.js API (зона ответственности `sherpa-outlook-plugin`).

## Зависимости
- React 18+, TypeScript, Vite
- Microsoft Fluent UI v9 (`@fluentui/react-components`, `@fluentui/react-icons`)
- `react-markdown`, `remark-gfm`
- Zero-Manual Mocks: Mock Service Worker (`msw`) или встроенный Mock EventSource/Fetch
- Тестирование: Vitest, React Testing Library
