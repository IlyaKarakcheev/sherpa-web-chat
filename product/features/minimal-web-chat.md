# Фича: Минималистичный веб-чат ассистента «Шерпа» (`minimal-web-chat`)

## Описание
Автономный веб-интерфейс диалога менеджера дистрибутора ПО с ИИ-ассистентом «Шерпа».

## Пользовательские сценарии
1. **Приветствие и начало работы:** При открытии чата отображается приветствие Шерпы и аватар со статусом "В сети".
2. **Запрос на подбор ПО:** Менеджер вводит запрос (например, по СУБД, операционным системам, офисным пакетам или лицензированию 1С) и получает структурированный ответ с Markdown-разметкой и таблицами.
3. **Индикация процесса:** Во время обработки отображается анимированный индикатор набора текста («Шерпа печатает...»).
4. **Удобный ввод:** Поддержка отправки по `Enter` и переноса строки по `Shift + Enter`, автоподстройка высоты текстового поля.
5. **Очистка истории:** Кнопка в шапке сбрасывает диалог к начальному состоянию.
6. **Обработка сбоев:** При возникновении ошибки сети или мока выводится сообщение об ошибке с возможностью повтора.
