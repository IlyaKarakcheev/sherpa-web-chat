# Единая спецификация функциональности Sherpa Web Chat (`product/SPECIFICATION.md`)

---

## 1. Общие сведения и назначение (`minimal-web-chat`)

Автономный тонкий веб-интерфейс диалога менеджера компании-дистрибутора ПО с ИИ-ассистентом «Шерпа».

### Пользовательские сценарии
1. **Приветствие и начало работы:** При открытии чата (Mock и Live) отображается индикатор «Подключение...» в ленте, а элементы ввода (поле сообщения, скрепка прикрепления файлов, кнопка отправки) заблокированы на время выполнения запроса к оркестратору. При успешном соединении статус переходит в "В сети", элементы разблокируются и выводится персонализированное приветствие. Сбой оркестратора (недоступность сервера/ошибка сети) выводится в ленту в виде системного сообщения с красным оформлением (`sender: 'system'`) и чипом «Повторить». Недоступность подсистем 1С CRM / GliNER обрабатывается текстом в реплике ассистента (`sender: 'assistant'`).
2. **Запрос на подбор ПО:** Менеджер вводит запрос (например, по СУБД, операционным системам, офисным пакетам или лицензированию 1С) и получает структурированный ответ с Markdown-разметкой и таблицами.
3. **Индикация процесса:** Во время обработки запросов и подключения отображается анимированный индикатор набора текста («Шерпа печатает...» / «Подключение...»).
4. **Удобный ввод и Server-Driven Placeholder:** Поддержка отправки по `Enter` и переноса строки по `Shift + Enter`, автоподстройка высоты текстового поля. Текст подсказки в поле ввода (`placeholder`) управляется сервером/оркестратором и динамически обновляется под контекст текущего шага диалога. Блокировка ввода активна только во время выполнения запроса (`isConnecting` / `isBusy`). При ошибке связи поле ввода остаётся доступным для ввода новых запросов или повтора. При отправке сообщения с прикрепленным файлом без введенного текста сообщению по умолчанию присваивается текст `"прикрепил файл"`.
5. **Очистка истории:** Кнопка в шапке сбрасывает диалог к начальному состоянию.
6. **Режимы работы (Mock / Live):** Чат поддерживает автономный демонстрационный режим с Zero-Manual Mocks (`?mock=true` или по умолчанию) и промышленный режим интеграции с живым бэкендом/оркестратором (`?mock=false` или `window.SHERPA_CONFIG = { mode: 'live', apiUrl: '...' }`).

## 2. Сценарий ассистента продаж и 1С CRM (`sales-assistant-mock-scenario`)

Работа с 1С CRM и разбором входящих запросов/писем от партнеров (системных интеграторов и реселлеров) по лицензированию и оформлению сделок.

### Система индикации связи и теги сервисов
1. **Статус доступности оркестратора (Presence Dot):**
   - 🟢 **Зеленая точка (`#107c10`):** Сервер / оркестратор ассистента доступен («В сети»).
   - 🔴 **Красная точка (`#c42b1c`):** Сервер / оркестратор недоступен («Нет связи с сервером»).
2. **Теги подключенных сервисов (Service Tags в шапке):**
   - Теги `1C CRM`, `GliNER` отображаются в шапке в нейтральных серых тонах.
   - Список сервисов передается в полезной нагрузке ответов оркестратора (`services: [{ id, name }]`).
3. **Обработка доступности сервисов в диалоге:**
   - **Сервис 1С CRM:** При отключении/недоступности ассистент блокирует операции записи/связывания сделок и предлагает консультации по каталогу.
   - **Сервис GliNER:** При недоступности информирует о невозможности автопарсинга письма и предлагает ручной ввод.

### Интерактивный 5-шаговый сценарий
1. **Приветствие и авторизация в 1C CRM:** Динамическое приветствие с быстрыми кнопками: `[Обработать открытое письмо]`, `[Создать сделку вручную]`, `[Консультация по лицензиям]`.
2. **Извлечение данных из входящего письма:** Извлечение контрагентов, заказчиков (Deal Registration), списка продуктов и подбор сделки в 1С CRM.
3. **Просмотр альтернативных сделок:** Вывод карточек активных сделок партнера с метаданными и кнопками связывания.
4. **Связывание письма со сделкой в 1С CRM:** Двухфазное подтверждение `[Связать]` / `[Отмена]`, генерация навигационной ссылки 1С (`e1cib/data/...`).
5. **Создание новой сделки в 1С CRM:** Валидация полей и регистрация документа в 1С CRM.

## 3. Панель настроек и диагностика (`settings-and-diagnostics-panel`)

Графический интерфейс конфигурации (Settings Modal) для переключения между Mock и Live HTTP, настройки эмуляции и просмотра системного журнала событий.

### Функционал панели
1. **Открытие и закрытие:** Вызов по кнопке `[⚙️]`, закрытие по `[✕]`, клику по фону или `Escape`.
2. **Выбор режима:**
   - `● Режим Mock` — работа через `MockSherpaService`.
   - `○ Режим Live` — работа через `HttpSherpaService` с REST API оркестратора.
3. **Настройки Mock:** Выбор состояния 1С CRM (Online / Offline / Detached), GliNER (Online / Offline / Detached) и Оркестратора (Online / Offline), имя менеджера и задержка ответа (мс).
4. **Настройки Live:** Базовый URL API и токен авторизации (Bearer JWT).
5. **Журнал событий (Logs & Diagnostics):** Фиксация категории логов (`[SYS]`, `[USER]`, `[ASSISTANT]`, `[HTTP]`, `[ERROR]`), кнопки `[Очистить]` и `[Копировать]`.
6. **Применение настроек:** Кнопка `[Применить]` сохраняет параметры в `localStorage` (`sherpa_settings`) и перезапускает клиент без потери контекста.
