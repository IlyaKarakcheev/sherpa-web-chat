# sherpa-web-chat

**sherpa-web-chat** — это легковесный автономный веб-интерфейс ассистента «Шерпа» для менеджеров компании-дистрибутора ПО. Интерфейс выполнен в дизайн-системе Fluent UI и оптимизирован для подбора лицензий, проверки совместимости отечественного ПО (реестр Минцифры РФ), расчета спецификаций и консультаций по прайс-листам.

---

## 1. Статус и версия
- **Версия:** `0.1.0` (SemVer)
- **Статус:** `Prototype` (готов к передаче на приемку аналитику/человеку)
- **Проверенная ревизия:** `main`

---

## 2. Что нового в версии 0.1.0
- Минималистичный интерфейс окна чата в стиле Fluent UI (заголовок с аватаром и статусом "В сети", кнопка сброса).
- Рендеринг Markdown в ответах ассистента: таблицы СУБД/ОС/Офиса, списки, выделения, цитирование.
- Индикатор набора текста («Шерпа печатает...»).
- Удобный ввод: многострочный Textarea с автоподстройкой высоты, отправка по `Enter`, перенос по `Shift + Enter`.
- Интерактивные чипсы-подсказки (быстрые вопросы по клику).
- Встроенный мок-провайдер Zero-Manual Mocks (`mocks/mock-assistant.js`) по контракту OpenAPI 3.1.
- Автоматические тесты (позитивные сценарии консультаций + обработка сетевых ошибок 500).

---

## 3. Инструкция по развертыванию и запуску

Компонент является полностью автономным и не требует сборщиков или сложных зависимостей.

### Вариант А: Прямой запуск в браузере (быстрый старт)
1. Откройте файл `index.html` или `src/index.html` в любом современном браузере (Chrome, Edge, Firefox, Safari).
2. Чат сразу готов к работе на встроенных моках подбора ПО.

### Вариант Б: Запуск через локальный HTTP-сервер
Для корректной работы ES-модулей в строгих политиках безопасности браузера:
```bash
# Через npx serve (или любой статический сервер)
npx serve .

# Либо через встроенный Python
python -m http.server 3000
```
После запуска откройте `http://localhost:3000` в браузере.

---

## 4. Запуск автоматических тестов

Тесты написаны на встроенном раннере Node.js (`node --test`) без внешних зависимостей:
```bash
npm test
```

Проверяются:
- Контракт и сценарии ответов мок-провайдера (СУБД, ОС, 1С, офисные пакеты).
- Обработка сбоев генерации и сетевых отказов (HTTP 500 / `LLM_SERVICE_UNAVAILABLE`).
- Парсинг Markdown-таблиц и элементов форматирования.
